# Projeto Prático — Login e Galeria de Fotos

**Disciplina:** Desenvolvimento Web III 

## 1. Descrição do projeto

Este projeto consiste em uma aplicação web com tela de login e uma galeria de fotografias, utilizando HTML, CSS, JavaScript, Bootstrap e a API pública JSONPlaceholder.
Após realizar o login corretamente, o usuário terá acesso à galeria de fotos, podendo visualizar as imagens e seus títulos.

## 2. Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- API JSONPlaceholder

## 3. Como executar o projeto

1. Baixe ou extraia todos os arquivos do projeto para uma mesma pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Execute utilizando a extensão Live Server.
5. O projeto será aberto no navegador.

**Importante:** É necessário ter conexão com a internet para acessar as APIs.

## 5. APIs utilizadas

**API de usuários:**

https://jsonplaceholder.typicode.com/users

Utilizada para validar o usuário e a senha.

**API de fotografias:**

https://jsonplaceholder.typicode.com/photos

Utilizada para buscar as fotografias exibidas na galeria.

## 6. Funcionalidades

- Tela de login com validação dos dados.
- Consulta de usuários pela API.
- Exibição de 20 fotografias inicialmente.
- Miniaturas com dimensões de 32 × 32 pixels.
- Visualização ampliada das fotografias.
- Exibição do título completo de cada foto.
- Opção para voltar à lista de fotografias.
- Botão para sair e retornar à tela de login.
- Mensagens de carregamento e tratamento de erros.
